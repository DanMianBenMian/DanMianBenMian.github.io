RyConsole 更新日志

从 2026-07 的 v1 旧款，到 2026-09 全新的 V2 研究控制台（今天 81 个原生桥）的安全研究 harness —— 这里按版本记录每一次真实改动。最新版为 V2.4.21。

版本时间线

V2.4.212026-09-25最新
  • ★ callPtr 变参缺陷修复：旧 callPtr 用固定原型分发 → 实参全走寄存器，而 arm64 ABI 变参函数未命名实参必须上栈 → syscall ≥1 实参静默返回假 EINVAL/ENOENT（0 实参正常）。
  • 新增 callVariadic(addrHex,args,opts) —— 走真·变参函数指针原型（clang 自动上栈，无 libffi/汇编），返回 -1 附 errno 透传（当场分清 EINVAL/EPERM），{buf:} 槽回传 bufAddrN。
  • 新增 syscallN(number,args,opts) —— 号段校验（kern.nsysent，读不到退 512）+ csops(45) 死亡名单默认拦截（{allowDead:true} 放行）→ 越界号从「SIGSYS 杀进程」变受控报错。
  • 原生原语 79 → 81。
真机验收：msync 经 callVariadic 与非变参直调 A/B 应同为 0x0；syscallN(202,…) 失败时看 errno（定性 P1「errno 生死」）。
V2.4.202026-09-25
  • ★ Tier 3 原生 Mach 竞态桥（RACE_plan_v2 §3）：解锁此前被 bridge_iokit 用户态 ryConnProblem 体检封死的 ipc_port/vm_map 内核竞态面。
  • 新增 9 原语：portAlloc/portInsertRight/portDealloc/portDestroy/portModRefs/portType（mach_port 生命周期）+ vmAlloc/vmDealloc（vm_map 并发）+ iokitCallPort（跳过体检直发内核）。
  • 原生原语 70 → 79。
⚠️ Mach/vm UAF 可能触发 kernel panic（设备重启）；探针 ITERS 已保守（800），真命中再降 iters 复现并抓 guardAddr+lastPrim。
V2.4.192026-09-25
  • ★ envReset 回归修复（JSC 桥转换坑）：无参 envReset() 在真机竟停了服务端（违背 V2.4.15「默认不停」）—— 根因是 JS 不传参时 undefined 被 JSC 转成非零 NSNumber。改注册点改用 JSValue* 参数 + 判空兜底。
  • 通用坑：所有声明 NSNumber*/BOOL 形参的原语，无参调用都会踩同样的坑，统一 JSValue 参数 + 判空。
V2.4.182026-09-25
  • ★ 新增 envCred() 身份原语：{uid,euid,gid,egid,groups[],login} —— uid/euid 拆开报是故意做成的实时 LPE 金丝雀（真提权时 uid→0 或 euid→0）。返回值保留原始数值不替换名字。
  • ★ 修复 liveHits 灵动岛焊接 Bug：doPush() 抛错后收账代码被跳过 → pushInFlight 永久 true → 灵动岛焊死在 0。defer 兜底后管道不再卡死。
  • build_ui.py 推送清单修复：旧清单漏推 Swift 文件，导致云构建用仓库旧版；改为完整遍历 PayloadApp/RyConsoleScripts/tools。
V2.4.172026-09-25

  • 新增 RYTopVCForPresent() 解决 iPad 弹窗需锚点否则崩的问题。
V2.4.162026-09-25
