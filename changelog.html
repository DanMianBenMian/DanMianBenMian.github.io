RyConsole 更新日志

从 2026-07 的 v1 旧款，到 2026-09 全新的 V2 研究控制台（今天 81 个原生桥）的安全研究 harness —— 这里按版本记录每一次真实改动。最新版为 V2.4.26。

版本时间线

V2.4.262026-09-29最新
  • ★ 远程连接模式补上本机日志 + 侧栏状态：之前远程模式下 PC 推来的探针 / print 输出 / result 回传只发回 PC，本机面板看不到；现 iPad 端加环形日志缓冲，三处埋点（收到 push_js 代码、print 输出、result 回传）实时显示在「连接日志 / 执行输出」面板，与监听模式一致。
  • ★ 侧栏左下角状态镜像监听：远程连接中显示「● 远程连接中」（琥珀）/ 已连接显示「● 远程已连接」（绿）/ 未开显示「● 未启动」（灰），不再像以前那样连上了仍灰着。
  • 监听 / 远程互斥状态都归并到同一侧栏指示器，外壳加 1s 轮询同步。
V2.4.252026-09-29
  • ★ 修复远程连接模式顶层 return 非法：之前远程执行路径直接 evaluateScript 全局 eval，顶层 return 触发 SyntaxError 整段失败；现与局域网 / Autorun 模式一致走 RYC_RUN（engine.js 包裹），支持 return 回传结果。
  • 零副作用：保留全局 var 跨 push_js 共享，仅补上 return 支持；与 V2.4.24 的远程连接 / 保活 / 灵动岛能力完全兼容。
V2.4.242026-09-28
  • ★ 远程连接（RyConsoleServer + Cloudflare quick tunnel 穿透）：iPad 经公网隧道连家里 PC，PC 推 JS 在 iPad 的专用 ryc-remote 上下文执行并回传，实验室外（学校 4G / 蜂窝）也能跑。
  • ★ 远程保活 + 灵动岛「远程连接中」：完全镜像监听架构 —— 点「连接」即拉起静音音频后台保活 + 独立实时活动（☁️ 蓝色云图标），划出 App 不再 60s 掉线；WS 不可达时自动降级 HTTP 长轮询。
  • 监听 / 远程互斥：同时只能开一个，开启另一个会先提示并踢掉当前。
V2.4.232026-09-25
  • ★ 回退 callPtr 到固定元数：2.4.22 让 callPtr 走变参通道，固定元数 libc（memset / kill / mmap 等）x1–x7 实参被破坏、多参结果错误（回归）。现 callPtr 回固定元数寄存器传参，多参 / syscall 恢复正常；真变参（printf 等）仍走 callVariadic，受控 syscall 走 syscallN。
  • errno 两条路径失败都附（坏 pid 可验 errno=3 ESRCH）；原生原语合计 81。
V2.4.222026-09-25
  • ⚠ 已知回归：callPtr 误走变参通道，多参 libc 调用结果错误，已由 V2.4.23 回退修复；单参调用不受影响。
V2.4.212026-09-25
  • 新增 callVariadic(addrHex,args,opts) / syscallN() 变参原语（callPtr 入口本身的变参修复在 V2.4.22 补齐）。
  • 新增 callVariadic(addrHex,args,opts) —— 走真·变参函数指针原型（clang 自动上栈，无 libffi/汇编），返回 -1 附 errno 透传（当场分清 EINVAL/EPERM），{buf:} 槽回传 bufAddrN。
  • 新增 syscallN(number,args,opts) —— 号段校验（kern.nsysent，读不到退 512）+ csops(45) 死亡名单默认拦截（{allowDead:true} 放行）→ 越界号从「SIGSYS 杀进程」变受控报错。
  • 原生原语 79 → 81。
真机验收：msync 经 callVariadic 与非变参直调 A/B 应同为 0x0；syscallN(202,…) 失败时看 errno（定性 P1「errno 生死」）。
V2.4.202026-09-25
  • ★ Tier 3 原生 Mach 竞态桥（RACE_plan_v2 §3）：解锁此前被 bridge_iokit 用户态 ryConnProblem 体检封死的 ipc_port/vm_map 内核竞态面。
  • 新增 9 原语：portAlloc/portInsertRight/portDealloc/portDestroy/portModRefs/portType（mach_port 生命周期）+ vmAlloc/vmDealloc（vm_map 并发）+ iokitCallPort（跳过体检直发内核）。
  • 原生原语 70 → 79。
⚠️ Mach/vm UAF 可能触发 kernel panic（设备重启）；探针 ITERS 已保守（800），真命中再降 iters 复现并抓 guardAddr+lastPrim。
V2.4.192026-09-25
  • ★ envReset 回归修复（JSC 桥转换坑）：无参 envReset() 在真机竟停了服务端（违背 V2.4.15「默认不停」）—— 根因是 JS 不传参时 undefined 被 JSC 转成非零 NSNumber。改注册点改用 JSValue* 参数 + 判空兜底。
  • 通用坑：所有声明 NSNumber*/BOOL 形参的原语，无参调用都会踩同样的坑，统一 JSValue 参数 + 判空。
V2.4.182026-09-25
  • ★ 新增 envCred() 身份原语：{uid,euid,gid,egid,groups[],login} —— uid/euid 拆开报是故意做成的实时 LPE 金丝雀（真提权时 uid→0 或 euid→0）。返回值保留原始数值不替换名字。
  • ★ 修复 liveHits 灵动岛焊接 Bug：doPush() 抛错后收账代码被跳过 → pushInFlight 永久 true → 灵动岛焊死在 0。defer 兜底后管道不再卡死。
