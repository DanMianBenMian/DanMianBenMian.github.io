Html App Build

一个 Windows 桌面小工具：把你用 TurboWarp / Scratch 导出的 .html 作品， 一键打包成 iOS（.ipa） 和 Android（.apk） 原生安装包。 填好名字、图标、权限、旋转方向，剩下的交给云端构建，直接拿安装包。

这是什么

很多学过图形化编程的人，做出来的作品只能停留在浏览器里。Html App Build 做的事很简单： 把那个能跑的网页，套进一个真正的手机 App 壳子里——iOS 用 WKWebView，Android 用 WebView， 再走云端流水线把安装包编译、签名处理好。你不需要装 Xcode、不需要配 Android Studio， 点一下「构建」，过一会儿安装包就回来了。

能做什么

01

双平台打包

同一份 .html，既能出 iOS 的 .ipa，也能出 Android 的 .apk。

02

自定义信息

App 名字、图标、包名（Bundle ID）都能自己填，装进手机显示的是你起的名。

03

权限清单

按平台勾选可申请的权限（相机、相册、定位……），自动写进对应配置。

04

旋转方向

竖屏 / 横屏 / 自适应 三档可选，适配不同玩法的作品。

05

云端构建

编译、签名都在云端完成，本机只负责上传配置、下载成品。

06

零环境门槛

不用自己装 Xcode / Gradle，开箱即用，适合非专业开发者。

怎么用

  1. 从 TurboWarp / Scratch 把作品打包成 .html（含全部资源、单文件最好）。
  2. 下载并打开 Html App Build（Windows 版），选要出的平台：iOS 或 Android。
  3. 上传 图标、填写 App 名字 与 包名，按需勾选权限、选好旋转方向。
  4. 点「构建」，工具把配置传到云端流水线，开始编译并签名。
  5. 构建完成后下载 .ipa / .apk，装到手机上就能玩了。
关于安装：iOS 的 .ipa 需要通过自签 / 证书侧载（如爱思助手、牛蛙等）装到设备； Android 的 .apk 在允许「未知来源」后可直接安装。具体怎么装属于各平台侧载常识，这里不展开。

注意事项（说实话）

它是「网页套壳 App」，不是把图形化逻辑重写成本地原生代码。好处是简单、快、零环境； 代价是：App 本质是个内嵌浏览器，需要联网才能跑的作品要自己保证资源可达， 且摄像头 / 麦克风等系统能力受 WebView 限制，不是所有原生权限都能在套壳里真正用起来—— 勾了权限不代表功能一定可用，做之前先想清楚你的作品用不用得到这些硬件能力。

它适合：展示类、交互类、小游戏类作品，想快速装进手机分享给别人。
它不适合：强依赖系统硬件（深度相机 / 蓝牙外设）或要上架 App Store 的正式产品。
