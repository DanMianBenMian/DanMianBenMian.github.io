A14 / iPadOS 27 β2 的 pmap 后端定性：SPTM + TXM 已收口

对 kernelcache.release.ipad13pb 做静态二进制取证 + 沙盒侧动态边界探测。决定性判据是 load command 的段命名约定 __DATA_<BACKEND> —— 全文件 __DATA_SPTM 命中 3 次、__DATA_PPL / __DATA_APRR 命中 0 次，据此把后端定性为 SPTM + TXM（非 PPL / APRR）。附四路交叉印证、__DATA_SPTM 全零的正确解读、3 条自我推翻记录与 2 项工程缺口。
