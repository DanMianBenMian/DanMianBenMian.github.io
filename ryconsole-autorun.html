RyConsole Autorun

一个 Windows 命令行工具：让 AI 在电脑端把 JS 探针 发到局域网里的 iPad （RyConsole App）执行，再把结果回传。用来给 iOS 安全研究做 自测与动态验证——复杂的研究，也能在自己手上跑起来。

这是什么

它是一套两端协作的自测系统：iPad 上跑 RyConsole 的研究控制台（内置 AutorunServer，监听 8899 端口），电脑上跑这个 ryc_autorun 客户端。AI 在电脑端组织好要跑的 JS 探针， 通过局域网发给 iPad 执行，iPad 把打印和返回值回传，AI 再接着分析。整套链路 纯本地局域网，探针只在你自己的设备沙盒里跑，不需要把代码传到任何云端。

能做什么

01

局域网直连

ping / run / eval / submit / result 五个子命令，覆盖连通测试到结果轮询的完整流程。

02

单文件 exe

打包成约 8.1 MB 的独立 exe，不需要任何 Python 环境，双击即用、可随 U 盘带走。

03

极简协议

走极简 HTTP，纯标准库实现，无第三方依赖，源码一眼能审完。

04

AI 可驱动

配套 ryconsole-autorun Skill，AI 加载后会先问清 exe 位置，再自动连设备、发探针、解析回传。

05

安全边界

只在自己拥有 / 授权的设备上使用，探针运行于 App 沙盒内，并附 Responsible Disclosure 声明。

06

开源可审

客户端源码完全公开，iPad 端原生桥原语（jb* / iokit*）清单透明，研究者可自行核验。

怎么用

  1. 在 iPad / iPhone 上装好 RyConsole（未签名 IPA 侧载），打开 App。
  2. 左侧 Autorun 面板点「启动监听」，等圆点变绿、显示 :8899。
  3. 电脑上下载 ryc_autorun.exe，终端先测连通：ryc_autorun.exe ping --host <iPadIP>。
  4. 发探针：ryc_autorun.exe run --host <iPadIP> --code-file probe_env.js --json --quiet。
  5. 等 iPad 回传（客户端自动轮询最多 12 次），终端打印执行结果与返回值。
关于监听（V2.2 起已解决后台挂起）：点「启动监听」后 App 自动进入保活态 —— 静音音频循环 + 后台任务续期，此时可以切后台、可以锁屏，电脑端仍能连上； 灵动岛 / 锁屏上会显示「监听中」+ 端口 + 连接数 + 已运行时长。停止监听即释放保活，不做后台偷跑。 连不上时优先查：同一 Wi-Fi、端口没被占、iPad「本地网络」权限已允许。

注意事项（说实话）

它是 自己设备上的研究自测通道，不是越狱工具、也不是现成的漏洞利用。好处是 本地、可控、可复现；代价是：App 本质还在沙盒里—— externalMethod 有二次门禁，"能连上（OPEN_OK）"不等于"可利用"，真要拿到内核原语还得走动态验证。 做之前先想清楚你的研究目标，并只对自己拥有 / 授权的设备下手。

它适合：iOS 安全研究的自测、探针验证、AI 辅助的动态探索。
它不适合：对他人设备下手、绕过沙盒做未授权操作——那既违规也违法，本工具不提供也不鼓励。
