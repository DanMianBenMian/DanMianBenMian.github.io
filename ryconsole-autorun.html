RyConsole
Autorun

一个 Windows 命令行工具：让 AI 在电脑端把 JS 探针 发到局域网里的 iPad（RyConsole App）执行，再把结果回传。 用来给 iOS 安全研究做自测与动态验证 —— 复杂的研究，也能在自己手上跑起来。

单文件 exe纯标准库iPadOS 侧载AI 可驱动
下载 Windows 工具 下载 iPad App（IPA）
01

这是什么

电脑当「发射手」，iPad 当「执行手」，中间只跑一条最简的 HTTP。

02

能做什么

F / 01

局域网直连

ping / run / eval / submit / result 五个子命令，覆盖连通测试到结果轮询的完整流程。

F / 02

单文件 exe

打包成约 8.1 MB 的独立 exe，不需要任何 Python 环境，双击即用、可随 U 盘带走。

F / 03

极简协议

走极简 HTTP，纯标准库实现，无第三方依赖，源码一眼能审完。

F / 04

AI 可驱动

配套 ryconsole-autorun Skill，AI 加载后会先问清 exe 位置，再自动连设备、发探针、解析回传。

F / 05

安全边界

只在自己拥有 / 授权的设备上使用，探针运行于 App 沙盒内，并附 Responsible Disclosure 声明。

F / 06

开源可审

客户端源码完全公开，iPad 端原生桥原语（jb* / iokit*）清单透明，研究者可自行核验。

03

怎么用

四步：装 App → 开监听 → 测连通 → 发探针。

  1. 在 iPad / iPhone 上装好 RyConsole（未签名 IPA 侧载），打开 App。
  2. 左侧 Autorun 面板点「启动监听」，等圆点变绿、显示 :8899。
  3. 电脑上下载 ryc_autorun.exe，终端先测连通：
    ryc_autorun.exe ping --host <iPadIP>
  4. 发探针：
    ryc_autorun.exe run --host <iPadIP> --code-file probe_env.js --json --quiet
  5. 等 iPad 回传（客户端自动轮询，默认 3s×12；长探针可 --interval / --max-polls 自定义，一把等到底），终端打印执行结果与返回值。
04

边界（说实话）

它适合 / 不适合什么 它适合：iOS 安全研究的自测、探针验证、AI 辅助的动态探索。 它不适合：对他人设备下手、绕过沙盒做未授权操作 —— 那既违规也违法，本工具不提供也不鼓励。
